# Designing Better Products with AI & Figma

An interactive presentation by Mahmud Al Islam about AI-powered UI/UX design.

It is a single HTML page (`index.html`) with:

- a 3D city tower on the cover: click floor 18 to fly inside
- AI across the UX process, Figma foundations, Figma's built-in AI and the Figma agent
- live demos: Three.js 3D object, GSAP animations, a scroll-driven car story, splash screen and micro-interactions
- a design-token playground and 48 things we can build with AI

## How to view

Open `index.html` in Chrome, Edge or Safari (an internet connection is needed for fonts, GSAP and Three.js).

| Key | Action |
|---|---|
| → / Space | Next slide |
| ← | Previous slide |
| F | Fullscreen |
| ↓ / ↑ on slide 14 | Play the car story step by step |
